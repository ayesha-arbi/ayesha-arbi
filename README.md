## 🔬 Featured Projects

### 🤖 IssuePilot

AI agent for open-source contributors that turns confusing GitHub issues
into clear starter briefs by analyzing the issue, codebase, previous PRs,
relevant files, and difficulty.

**Stack:** TypeScript · Node.js · OpenAI · Octokit · GitHub Actions

---

### 🐛 AI-Powered PR Bug Predictor

An AI-powered pre-merge risk prediction system that estimates whether a
pull request is likely to introduce bugs.

Combines a **Gradient Boosting ML model** with an **LLM explainability agent**
to analyze repository history, code churn, and developer patterns.

**Stack:** Python · Pandas · NumPy · Scikit-learn · LLM APIs

---

### 🌍 Zameendar.ai

AI-powered land suitability analysis platform that evaluates locations for
agriculture, housing, industry, and renewable energy.

**Stack:** Next.js · React · TypeScript · Google AI · Maps APIs · Leaflet ·
Recharts

---

### 🚨 SIRENS

Agentic AI system for real-time urban crisis detection, planning, and
emergency response.

**Stack:** TypeScript · React · Firebase · Google Genkit · Google Maps

---

### 🦊 Speedfox

A browser extension that tracks video playback speed and shows users how
much time they save by watching videos faster.

**Stack:** JavaScript · HTML · CSS · Chrome Extension APIs
